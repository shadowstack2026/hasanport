Degree project

Wi-Fi sensing using ESP32-C3 devices

Feasibility of Integrated Sensing and Communication

The project examined whether ordinary 2.4 GHz Wi-Fi could be used for both communication and sensing with low-cost ESP32-C3 hardware.

I built a four-node setup and analyzed CSI, RSSI and Fine Time Measurement data to detect human presence and movement in indoor environments. The data was processed with Python and evaluated across static and dynamic scenarios.
